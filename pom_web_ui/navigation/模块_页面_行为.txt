Module: 数字阅片
 └── Page: 列表页 (类)
      ├── Tab: 我的代办  (列表类的不同状态)
      ├── Tab: 全部代办
      └── Tab: 回收站
           ↓
      打开项目（Action）
           ↓
 └── Page: 项目详情页
      ├── 玻片列表（Panel）
      ├── 右侧信息栏（Panel）
      └── 填写报告（Action）
           ↓
 └── Page: 报告编辑页
      └── 右侧信息栏（复用）


数字阅片 / 图文报告 / 报告管理
    在“页面模型层面”不是模块
    在“业务导航层面”是模块

    👉 二者不冲突

技术结论是：
    不是 Tab
    是「入口不同但落在同一类页面」

Tab 的定义是：
    同一页面内部切换
    不刷新整体结构
    上下文不变

而你这三个：
    顶部入口切换
    权限不同
    URL 不同
👉 所以不是 Tab

判断是不是模块：

    是否需要 Navigator 单独进入？
    是否有独立权限？
    是否是业务一级入口？

    ✔️ 是 → 业务模块

判断是不是 Page：

    DOM 是否高度相似？
    行为是否高度复用？
    能否通过 mode 区分？

    ✔️ 是 → 同一个 Page
